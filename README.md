# FitnessAI 💪🤖

An AI-powered fitness web application that helps users achieve their fitness goals with personalized workout guidance, exercise recommendations, and smart fitness tracking.

## 🚀 Features

* 🏋️ Personalized workout recommendations
* 🤖 AI-powered fitness assistance
* 📊 Fitness tracking and progress monitoring
* 🎯 Goal-based workout planning
* 📱 Responsive and user-friendly UI
* ⚡ Fast and interactive experience

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript / React 
* **Backend:** Node.js / Express 
* **Database:** MongoDB 
* **AI Integration:** OpenAI API / Gemini API 

## 📂 Project Structure

```bash
FitnessAI/
```

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/arpitdevda25/FitnessAI.git
```

### 2️⃣ Navigate to the project directory

```bash
cd FitnessAI
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server

```bash
npm start
```

The application will run on:

```bash
http://localhost:3000
```

## 🔑 Environment Variables

Create a `.env` file in the root directory and add the following:

```env
API_KEY=your_api_key_here
MONGODB_URI=your_mongodb_connection
```
